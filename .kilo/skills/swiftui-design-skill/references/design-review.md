# 5-Dimension Review

Score each dimension from 0 to 10. Ship only at 7 or above everywhere.

1. **Clarity**: the primary action and content are obvious in one second.
2. **Hierarchy**: title, section, body, and metadata are visibly distinct.
3. **Consistency**: spacing, radius, type, and color use tokens.
4. **Distinctiveness**: one memorable signature detail, no AI-slop pattern.
5. **Craft**: real alignment, optical spacing, tap targets, accessibility,
   loading and empty states.

Record the score in the review note when a screen changes.
